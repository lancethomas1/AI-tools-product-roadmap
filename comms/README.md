# Comms

Drafts and sent versions of point-of-view messages, governance proposals, and stakeholder notes related to this roadmap. Lives alongside the roadmap so the "why" and the "what" stay in one place.

## Conventions

- One file per message, named `YYYY-MM-DD-short-slug-[recipient].md`.
- Top of each file: a short frontmatter-style block — recipient, channel (Slack / email / doc), status (draft / sent / superseded), and a one-line purpose.
- Keep the body as the message text, ready to copy-paste. Edit in place; git history is the version log.
